# Example Output: Star Ground Artifacts

This directory demonstrates the artifact tree generated by Star Ground.

## Contents

- **Field Manuals/**: Printable checklists, one per project, with parts sorted by height.
- **Sticker Sheets/**: Avery 5160 labels for binning parts.
- **Source Documents/**: The build documents you gave, or a link to each preset's document at its publisher. This sample leaves them out, since the documents belong to their publishers.
- **Shopping List.csv**: The merged shopping list.
- **My Inventory Updated.csv**: The stock left after this build.
- **info.txt**: The version and date the pack was generated (this sample: v2.1.2).
